# External Integrations

**Analysis Date:** 2026-10-14

## APIs & External Services

**LLM & Reasoning Providers:**
- OpenAI API / Local LLM (Ollama or vLLM) - Powers LangGraph orchestration agents:
  - Assessment Agent (confidence evaluation, decision thresholds) in `rag_agentic/agentic_layer/`
  - Verification Agent (contradiction checking, hallucination reduction)
  - Reporting Agent (actionable rescue briefing synthesis)
  - SDK/Client: `langchain-openai` or standard `openai` Python SDK
  - Auth: `OPENAI_API_KEY` stored in `.env` (gitignored)

**Embedding & Reranking Services:**
- Hugging Face Hub / Sentence-Transformers:
  - Model downloads for local semantic dense embeddings (e.g., `all-MiniLM-L6-v2` or `BGE-small-en-v1.5`)
  - Cross-Encoder reranker models (e.g., `ms-marco-MiniLM-L-6-v2`) in `rag_agentic/rag_pipeline/`
  - Auth: `HUGGINGFACE_TOKEN` in `.env` if downloading gated models

**Drone & Aerial Imagery Feeds (Simulated / Field Inputs):**
- Aerial Video / RTSP / File Stream:
  - Simulated video files (`.mp4`, `.avi` from SARD / MOBDrone) read via OpenCV `cv2.VideoCapture`
  - Downlink frame stream passed to `detection/` inference pipeline

## Data Storage

**Vector Databases:**
- ChromaDB - Persistent vector database for Search and Rescue doctrine:
  - Location: Local persistent directory (`chroma_db/`, gitignored)
  - Client: `chromadb` Python library
  - Collections: Standard Operating Procedures (SOPs), wilderness first-aid, evacuation guidelines, maritime rescue doctrine

**External Datasets & Weights Repository:**
- Shared Google Drive:
  - URL: `https://drive.google.com/drive/folders/10CpW4MUXdUUGAECRarOE9qn1lQKXlFLo`
  - Purpose: Houses large artifacts not tracked in Git:
    - Datasets: SARD (Search and Rescue Dataset), MOBDrone (maritime drone imagery)
    - Model Checkpoints: Fine-tuned YOLO weights (`best.pt`), PPO policy weights (`ppo_search.zip`), embeddings cache
  - Storage paths locally: `data/`, `datasets/`, `models/weights/` (all ignored by `.gitignore`)

**File & Cache Storage:**
- Local filesystem for intermediate artifacts:
  - Extracted video frames in temporary directories
  - Generated route GeoJSON / coordinate arrays
  - Markdown rescue reports generated by Reporting Agent

## Authentication & Identity

**System Internal Auth:**
- Local workstation / internal network execution model:

  - No public multi-tenant user accounts required for initial MVP/semester scope

## Environment Configuration

**Development:**
- Required environment variables:
  - `OPENAI_API_KEY`: API key for LLM agents
  - `MODEL_WEIGHTS_PATH`: Path to local fine-tuned YOLO `.pt` file
  - `CHROMA_PERSIST_DIR`: Directory path for ChromaDB vector index
  - `FASTAPI_HOST`: Host for API server (default: `127.0.0.1`)
  - `FASTAPI_PORT`: Port for API server (default: `8000`)
- Secrets location:
  - `.env` in repository root (explicitly blocked in `.gitignore`)
  - Template provided via `.env.example`

## Webhooks & Endpoints

**FastAPI Endpoints (`route_dashboard/`):**
- `POST /api/v1/detect`: Receives aerial image/frame, returns target bounding boxes and confidence
- `POST /api/v1/search/plan`: Invokes RL search planning to compute next optimal aerial search waypoint
- `POST /api/v1/rag/query`: Queries tactical knowledge base for medical / rescue protocol
- `POST /api/v1/route/plan`: Computes safe extraction route (A*) given target coordinates and terrain grid
- `GET /api/v1/health`: Basic service status check
