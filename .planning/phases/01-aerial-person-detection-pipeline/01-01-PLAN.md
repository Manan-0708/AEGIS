    .planning/codebase/CONVENTIONS.md
    shared/schemas/detection.py
    detection/README.md
  </read_first>
  <action>
    Create `detection/infer.py` with:
    1. Model weight resolver `resolve_model_path()`:
       - Checks for custom weights in `detection/weights/best.pt`, `detection/weights/sard.pt`, or environment variable `MODEL_WEIGHTS_PATH`.
       - If found, loads custom weights.
       - If not found, falls back to `yolov8n.pt` and filters for class 0 (`person`).
    2. Importable function:
       `run_detection(source: str | np.ndarray, model_path: str | None = None, conf: float = 0.25, iou: float = 0.45) -> DetectionResult`
       - Runs inference via Ultralytics YOLO.
       - Extracts bounding boxes `[x1, y1, x2, y2]`, confidences, and labels.
       - Returns a validated `DetectionResult` Pydantic model.
    3. Annotation helper:
       `save_annotated_image(image_path: str, result: DetectionResult, output_path: str) -> str`
       - Draws bounding boxes and confidence tags on the image and saves to disk.
    4. CLI interface with `argparse`:
       - Flags: `--source` (required image or directory path), `--weights` (optional model path), `--conf` (default 0.25), `--iou` (default 0.45), `--save-json` (optional path to save output JSON), `--save-img` (optional path to save annotated preview).
       - Prints structured detection summary to stdout.
    5. Update `detection/README.md` with usage instructions, CLI examples, and team ownership documentation for Sujal and Vedant.
  </action>
  <verify>
    python -c "import inspect; from detection.infer import run_detection, resolve_model_path; assert inspect.isfunction(run_detection); print('Inference functions imported successfully')"
  </verify>
  <acceptance_criteria>

    - CLI runner accepts `--source`, `--conf`, `--iou`, `--save-json`
